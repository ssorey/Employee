A full-stack Employee Management system built with ASP.NET Core Web API,
Entity Framework Core, SQL Server, and a JavaScript front-end.
## Features
- CRUD operations for employees
- Full-time and part-time employees
- RESTful API
- Swagger UI
- SQL Server integration
- ## Tech Stack
- ASP.NET Core
- Entity Framework Core
- SQL Server
- HTML, JavaScript
- ## How to Run
1. Clone the repository
2. Update the connection string
3. Run `dotnet ef database update`
4. Run `dotnet run`
